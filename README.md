# InViTAG
Interactive grouping of image data for data science

With InViTAG, you can visualize, analyze, and group 100s images based on pixels and metadata, assisted with AI.

You can use it with natural images alone, images with metadata, or tabular and graphical representations of data.

## Features

- Load images and data from scratch or a previous grouping session
- Optimize the visual space tuning image size and numbers, collapsing or hiding groups, to fit your display.
- Zoom and compare images side by side
- Search images by ID or data range
- Explore image pattern diversity and spot outliers
- Generate groups manually, with AI-assisted clustering, or by categorical features
- Populate groups manually or with AI-assisted classification
- Check and clean up group content with outlier and inlier highlights, and feature-based visualization
- Name and save groups

InViTAG AI-assistance never takes the grouping decision for you. You see, you decide.

Try it out here: <a href="https://invitag.qcri.org/" target="_blank">https://invitag.qcri.org/</a>
